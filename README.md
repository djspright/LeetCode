### STEP1
1. 答えを見ずに考えて、5分考えてわからなかったら答えをみる。
2. 答えを見て理解したと思ったら、答えを隠して書く。
3. 筆が進まず5分迷ったら答えを見る。答えを見たら全部消してやり直す。
4. 通ったらSTEP1はクリア。

### STEP2
1. コードを読みやすくするようにできるだけ整える。
2. これで動くコードになったらSTEP2はクリア。

### STEP3
1. また全部消して、時間を測りながらもう一回書く。
2. 通ったらもう一度全部消して書き直す。
	- 10分以内に一回もエラーを出さずに書ける状態になるまで繰り返す。
3. 3回続けてそれができるようになったらクリア。
